시딩 노출 확인 — PC 도우미

왜 필요한가요?
  YouTube가 클라우드 서버에서의 영상 다운로드를 막습니다. 그래서 영상 분석(영상을 받아 장면을 AI로 보는 단계)만
  내 컴퓨터에서 실행합니다. 나머지(채널 수집, 댓글·링크 점검, 판정 보드)는 웹에서 합니다.

준비 (처음 한 번)
  1. Python 3.10 이상 설치: https://www.python.org  (설치 화면에서 "Add python.exe to PATH"를 체크)
  2. ffmpeg 설치: 명령 프롬프트에서  winget install Gyan.FFmpeg   (설치 후 창을 닫고 다시 열기)
  3. 이 폴더에서 명령 프롬프트를 열고:  python -m pip install -r requirements.txt

실행
  1. "실행.bat" 을 더블클릭합니다. (Mac/Linux: 터미널에서  python3 run_helper.py)
  2. OpenAI API 키를 붙여넣습니다. 화면에 보이지 않고, 파일에 저장되지 않습니다.
  3. 분석이 끝나면 이 폴더에 result.json 이 생깁니다.
  4. 웹 페이지의 "결과 올리기"에서 result.json 을 올립니다.

중간에 멈췄다면
  같은 방법으로 다시 실행하면, 이미 분석한 영상은 건너뛰고 이어서 합니다.

주의
  - 이 폴더에는 내 채널 목록과 분석 대상 영상 정보가 들어 있습니다. 끝나면 폴더를 지우세요.
  - 비용은 OpenAI 키의 계정에서 나갑니다. 웹에서 정한 비용 상한에 맞춰 영상 수를 줄여 두었지만, 실제 비용은 다를 수 있습니다.
  - 영상 다운로드가 막히면(403 등) 잠시 뒤 다시 실행하거나, 같은 네트워크에서 너무 많이 돌리지 마세요.
